The repository is the studio.

There is no hiring page, because there is nothing to get past. Every engine change, balance table and open bug lives in one Apache-2.0 repository — and a pull request from a stranger ships the same way ours does.

No template gauntlet. 03Ship your own game A workspace under packages/ with a game.json is listed here automatically. 04Bring art or sound Most sprites are placeholder-grade. Replacing one is a real contribution.
